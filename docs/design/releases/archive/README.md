# Archived release design docs

Historical design and implementation-plan documents for past releases. These
are kept for context on _why_ a decision was made at the time, but they are
**not** sources of truth for the current system — some describe intermediate
states that have since been superseded by later releases.

For the current architecture, see [`docs/ARCHITECTURE.md`](../../../ARCHITECTURE.md)
and the living component docs under `docs/design/components/` (e.g.
[`parser.md`](../../components/parser.md),
[`edit-applicator.md`](../../components/edit-applicator.md)). For the release
history and what shipped in each version, see
[`docs/ROADMAP.md`](../../../ROADMAP.md).
